# Zombie Game 🧟

# 

# About the Project

# 

# Zombie Game is a Python-based game developed using Pygame as part of our team hackathon project.

# 

# Technologies Used

# 

# \- Python

# \- Pygame

# \- PyInstaller

# 

# Source Code

# 

# The project source code is organized into separate Python files:

# 

# \- "main.py"

# \- "entities.py"

# \- "maze.py"

# \- "settings.py"

# \- "ui.py"

# 

# How to Run the Game from Source

# 

# 1\. Install Python on your computer.

# 

# 2\. Download or clone this repository.

# 

# 3\. Open a terminal in the project folder.

# 

# 4\. Install the required dependencies:

# &#x20;  

# &#x20;  "python -m pip install pygame"

# 

# 5\. Run the game:

# &#x20;  

# &#x20;  "python main.py"

# 

# Download the Game

# 

# The packaged Windows game will be available in the repository's Releases section.

# 

# Download the game package, extract it if it is a ZIP file, and run the game executable.
